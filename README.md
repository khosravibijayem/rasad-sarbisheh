# رصد سربیشه

پنل PHP فارسی با ذخیره‌سازی JSON، ورود مدیر و API دریافت خبر.

## وضعیت فعلی
پنل و API دریافت خبر در مخزن قرار گرفته‌اند، اما **اتصال ورود واقعی ایتا و سرویس زمان‌بندی‌شده هنوز نصب و آزمایش نشده است**. صرف داشتن GitHub Actions یا هاست PHP، خودش نشست ایتا ایجاد نمی‌کند.

## نصب پنل روی هاست اشتراکی
1. پوشه `rasad` را داخل `public_html` آپلود کنید.
2. آدرس `https://YOUR-DOMAIN/rasad/install.php` را باز کنید.
3. رمز مدیر و یک توکن محرمانه حداقل ۳۲ نویسه‌ای وارد کنید.
4. وارد `index.php` شوید.
5. داده‌ها و تنظیمات در `rasad/data` نگهداری می‌شوند و دسترسی وب به آن پوشه مسدود است.

## API دریافت خبر
درخواست POST به `/rasad/ingest.php` با هدر `Authorization: Bearer YOUR_TOKEN` و بدنه:
```json
{"items":[{"id":"unique-message-id","title":"عنوان","text":"متن خبر","summary":"خلاصه","source":"نام کانال","url":"https://eitaa.com/...","date":1790000000}]}
```
خبر تکراری بر اساس id حذف می‌شود.

## بررسی فنی اتصال ایتا
جزئیات endpointهای تأییدشده و موانع فنی در [سند بررسی اتصال ایتا](docs/EITAA-INTEGRATION.md) ثبت شده است. از جمله محدودیت دریافت ۱۰۰ گفتگو در هر فراخوانی و حافظه‌ای بودن مدیر نشست EitaaBun.

## اتصال ایتا
برای ورود و خواندن کانال‌های عضویت، سرویس جداگانه مبتنی بر Bun و پروژه غیررسمی [EitaaBun](https://github.com/ghaemifard/EitaaBun) لازم است. این سرویس باید روی میزبان دارای اجرای دائمی Bun راه‌اندازی و به API پنل متصل شود. GitHub Actions اجرای زمان‌بندی‌شده است، نه میزبان دائمی؛ بنابراین در این نسخه ادعای اتصال خودکار ایتا نمی‌شود.
